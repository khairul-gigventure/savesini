## 🤔 Pernahkah Anda Alami Masalah Ini?

1. **Bookmark merata-rata:** Jumpa tips bisnes di Twitter, panduan kerjaya di LinkedIn, resepi di Facebook, dan artikel di Google. Bila nak cari balik bulan depan, terus lupa simpan kat mana!
2. **Lupa kenapa kita simpan link tu:** Banyak kali kita tengok balik link yang dibookmark setahun lepas, tapi langsung tak ingat apakah poin penting yang kita nak pelajari dari post tersebut.
3. **Post asal kena padam:** Penulis padam post asal atau akaun ditutup, terus hilang semua mutiara ilmu yang kita simpan.

### 💡 Jawapannya: **SaveSini**
**SaveSini** dicipta untuk jadi *"second brain"* anda. Ia bertindak sebagai peti besi peribadi untuk mengumpul segala perkongsian ilmu, nota penting, dan rujukan bernilai tinggi dari pelbagai media sosial ke dalam **satu aplikasi yang kemas, laju, dan selamat**.

## ✨ Apa Yang Anda Boleh Buat Dengan SaveSini?

### 1. 📥 Simpan Link Dengan Sangat Pantas (Quick Capture)
* **Kesan Automatik:** Hanya tampal (*paste*) link, SaveSini akan automatik tahu link itu daripada Twitter/X, Threads, LinkedIn, atau Facebook.
* **Bercakap Guna Suara (Voice-to-Text):** Malas menaip nota panjang? Tekan ikon mikrofon dan bercakap sahaja — sistem akan tukarkan suara anda kepada teks nota secara automatik!
* **Elak Simpan Berulang:** Jika anda pernah simpan link tersebut sebelum ini, SaveSini akan terus beritahu supaya arkib anda tidak bersepah.

### 2. 🔍 Carian Laju Macam Kilat (Universal Search)
* Cari apa sahaja — tajuk artikel, nama penulis, link, hashtag, atau nota peribadi yang anda pernah tulis.
* Taip satu huruf pun keputusan carian akan terus keluar serta-merta tanpa perlu tunggu loading.
* Boleh tapis mengikut platform (contoh: nak tengok link LinkedIn sahaja) atau format (template, strategi, ringkasan).

### 3. 📁 Susun Mengikut Folder & Topik (Collections)
* Kumpulkan link mengikut minat anda — contohnya: *Pemasaran & Jualan*, *Kesihatan & Produktiviti*, *Idea Bisnes*, atau *Panduan Hidup*.
* Boleh letak ringkasan strategi untuk setiap folder supaya mudah dikongsi kepada rakan sepasukan atau keluarga.

### 4. 📰 Buat Ringkasan Mingguan 1-Klik (Weekly Digest)
* Nak kongsi ilmu yang anda kumpul minggu ini kepada orang lain? 
* Tekan butang **Weekly Digest**, dan SaveSini akan automatik susun semua link pilihan anda menjadi teks kemas yang sedia dihantar ke **WhatsApp**, **Telegram**, **Newsletter emel**, atau fail nota **Notion/Obsidian**!

### 5. 📖 Mod Bacaan Tenang (Focus Reader)
* Baca petikan isi penting tanpa gangguan iklan, komen toksik, atau notifikasi media sosial yang mengganggu fokus anda.

### 6. 👥 Akaun Peribadi & Selamat (Multi-User Cloud Sync)
* **Akaun Tersendiri:** Setiap orang ada ruang simpanan peribadi yang dilindungi sepenuhnya oleh pangkalan data **Google Firebase**.
* **Segerak di Semua Peranti (Sync):** Simpan link guna telefon semasa dalam tren, sampai di pejabat buka laptop, semua link terus ada di depan mata.

## 📱 Cara Pasang Sebagai Aplikasi di Telefon Pintar

SaveSini dibina menggunakan teknologi **PWA (Progressive Web App)**, jadi ia boleh dipasang terus ke telefon tanpa perlu muat turun dari App Store atau Google Play Store:

### 🍎 Bagi Pengguna iPhone (iOS Safari):
1. Buka link **[https://savesini.ai.studio](https://savesini.ai.studio)** di pelayar **Safari**.
2. Tekan ikon **Share** (anak panah ke atas di bahagian bawah skrin).
3. Skrol ke bawah dan pilih **"Add to Home Screen"** (*Tambah ke Skrin Utama*).
4. Selesai! Ikon SaveSini akan muncul di skrin utama telefon anda.

### 🤖 Bagi Pengguna Android (Chrome):
1. Buka link **[https://savesini.ai.studio](https://savesini.ai.studio)** di pelayar **Google Chrome**.
2. Tekan menu tiga titik (⋮) di bahagian atas kanan.
3. Pilih **"Install app"** atau **"Add to Home screen"**.
4. Tekan **Install** dan buka seperti aplikasi biasa.

## 🛠️ Untuk Pembangun / Developer (Jika Ingin Jalankan Sendiri)

Jika anda seorang pembangun perisian (*programmer*) dan ingin menjalankan aplikasi ini di komputer sendiri:

### 1. Muat Turun Kod
```bash
git clone https://github.com/<username-anda>/savesini.git
cd savesini
```

### 2. Pasang Dependency
```bash
npm install
```

### 3. Jalankan Aplikasi
```bash
npm run dev
```
Buka browser dan layari `http://localhost:3000`.

### 4. Kompilasi untuk Production
```bash
npm run build
```
